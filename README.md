# CDP page: review preview

Static preview of the Customer Data Platform (CDP) transformation capability page and its Capabilities overview tile, for internal review.

- `index.html`: landing page with links to the two pages
- `product/customer-data-platform/index.html`: the service page
- `capabilities-overview-tile.html`: the overview tile
- `assets/`: fonts and images used by the pages
- `.nojekyll`: tells GitHub Pages to serve the files as they are (no Jekyll build)
- `robots.txt` and a noindex tag on every page: asks search engines not to list it. This does not make the site private.

This is a draft. It is not the live xponent.ai site, and the final page goes into the WordPress site.
